One original single-line excuse (at most 200 characters) for skipping a pointless work meeting or Zoom call, written for the [make.fun bounty](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163).

## Entry

> Sorry — my Wi-Fi is fine, my camera works, my mic works. I've run out of technical excuses, so here's the honest one: I just don't want to be there.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt` (mode 0644) and to `./entry.txt`.

## Run

```sh
python3 main.py
```
